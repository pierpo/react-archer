# react-archer

🏹 Draw arrows between DOM elements in React 🖋

`react-archer` lets you declaratively draw arrows between elements. Wrap your
layout in an `ArcherContainer`, mark the endpoints with `ArcherElement`, and
describe the connections with `relations` — the library measures the DOM and
draws the SVG arrows for you.

## Installation

```bash npm2yarn
npm install react-archer --save
```
